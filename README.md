# 📊 Zomato Sales Dashboard – Power BI Project

This project presents a comprehensive *Zomato Dashboard* built using *Power BI*, visualizing key performance metrics such as order quantity, sales amount, ratings, food category performance, and geographical sales distribution.

## 🚀 Overview

The dashboard provides insights into:

* 💸 *Total Amount*: ₹987 Million
* 📦 *Total Quantity*: 2 Million items
* ⭐ *Total Ratings*: 148K
* 🛒 *Total Orders*: 150K

### 🍽 Category Breakdown:

* *Non-Veg*: 140K orders | 10K ratings
* *Veg*: 156K orders | 12K ratings
* *Other* (Snacks, Beverages): 14K orders | 927 ratings

---

## 📍 City-Wise Sales Quantity

A horizontal bar chart shows top-performing cities by quantity sold:

* Highest sales from *Electronic City, followed by **Old Gurgaon* and *Gorakhpur*.

---

## 📅 Yearly Sales Trend

A line graph displaying total sales amount by year:

* Peak sales in *2018* at ₹1M
* Gradual decline to ₹0.4M in *2020*

---

## 🎯 Filters and Views

* Toggle between *Amount* and *Quantity* views
* City filters: All Sales, Top 5, Top 10, Top 20, etc.

---

## 🛠 Tools Used

* *Power BI Desktop*
* DAX (Data Analysis Expressions)
* Excel/CSV (Data Source)

## 📌 Key Learnings

* Building interactive dashboards
* Analyzing customer and location-based performance
